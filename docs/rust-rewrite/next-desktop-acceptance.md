验证统一由 GitHub Actions 执行，本地只修改代码和做必要检查。
[fa5a75fde 的四平台运行](https://github.com/HeDaas-Code/Drifting/actions/runs/44577536145)
中 macOS、Linux 的完整测试、构建和门禁通过；Windows x64、ARM64 的构建和门禁通过，
测试暴露了 Unix 专用路径夹具、依赖 Explorer 的托盘队列测试以及 Win32 原子移动的长路径问题。
本轮分别改为原生临时绝对路径、独立测试控制器队列，以及规范化父目录后调用
`MoveFileExW`（保留末段与符号链接移动语义），并增加超过 MAX_PATH 的原子覆盖回归测试。
修复后的四平台结果以新 GitHub 运行记录为准，尚未返回时不记为通过。

Linux 与 Windows x64 的真实 CPU 合成听写已通过该运行；macOS/ARM64 未跑此项。
本地按需模型下载与校验、运行时分发和协议子进程夹具已实现。
此前真实 Codex MCP 写作、回执、隔离和撤权通过；DSH 因其默认 ACP profile 缺少
模型凭据而阻断。中文麦克风、原生 X11/Wayland 和安装包内人工交互仍待验收。
