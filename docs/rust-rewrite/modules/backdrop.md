# 背景

设置的「外观 → 背景」提供内置字海、纯色和自定义图片。自定义图导入为应用私有目录中的原始文件和 PNG 预览，支持 PNG、JPEG、WebP，尺寸和内存解码有限制，并可用 0–40 的滑块重新生成模糊预览。窗口使用 cover 方式铺满背景；自定义图存在时背景之上的菜单、侧栏、对话框和底栏使用透明玻璃，正文纸面与文字保持可读。

图片失效时回到纯色模式并保留失效配置，设置页显示替换或移除入口。导入仅允许本地文件，原始图片复制到应用配置目录，源文件不被修改。选择、替换、模糊强度和移除后刷新所有窗口；设置和图片不随作品同步。

自动验收覆盖原图字节保留、PNG 预览、模糊变化、路径穿越拒绝、损坏图片拒绝和原图不被替换。亮暗主题、降低动效、图片失效、X11/Wayland 窗口和 Windows 打包内的真实视觉结果仍需桌面验收。
