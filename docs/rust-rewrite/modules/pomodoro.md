# 写作番茄钟

标题栏的计时按钮打开番茄面板。默认专注 25 分钟、短休息 5 分钟、每四轮长休息 15 分钟；面板可单独调整三种时长，并提供开始、暂停、继续、结束与静音。设置和当前阶段、截止时间、暂停剩余时间、起始作品、书名、阶段时长及会话标识保存在设备设置的一份版本化记录中。

计时由应用级任务推进，不依附某个工作区窗口。关闭所有窗口或休眠不会丢失截止时间；重新打开时按绝对期限推进过期阶段。休眠前已开始的专注最多结算一轮。若随后的休息也已结束，从恢复时才开始下一轮专注。焦点阶段完成先向作品库本地 SQLite 写入唯一完成记录，再切换到休息阶段；跨午夜时用原定截止时间计算作者本地日期。记录主键由会话与单调焦点序号组成；若应用在写入后、保存新计时状态前退出，恢复时重试只会命中同一条记录。重试若带着不同作品或时长，则拒绝推进并保留计时状态供重试。

完成记录不进入书籍同步，也不混入写作日字数。作品「统计」读取本地完成记录，显示当天轮数、累计轮数及累计专注分钟；记录携带开始时的作品 ID，即使作者在计时期间切换作品，归属不变。

针对性验收：`dr-shell` 的可控时间状态测试覆盖截止时间、暂停/恢复和连续三个四轮周期；`dr-store/tests/pomodoro.rs` 覆盖唯一写入、主键内容冲突、跨重开、作品隔离和日期/时长验证；`dr-view-stats/tests/v3.rs` 覆盖统计读取与重复事件。真实桌面通知声以及 Linux/X11、Wayland、Windows 的外壳体验需要打包运行验收。
